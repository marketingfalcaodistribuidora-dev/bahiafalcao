# Documentação

- `design/`: exportações do Claude Design, uma pasta por página (ex.: `01-sobre-a-empresa/Sobre.dc.html`). São a referência visual do site e **não devem ser editadas**. Para visualizar, sirva a pasta (ex.: `npx serve docs/design/01-sobre-a-empresa`) e abra o `.dc.html`.

Coloque aqui novas exportações de design, decisões de arquitetura (ADRs) e guias.
