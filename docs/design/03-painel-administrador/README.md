# 03 — Painel do administrador (referência de design)

Protótipo navegável do painel do catálogo, aprovado pelo responsável em 2026-11-11 (specs 003 e 004).
Abra `Painel.html` no navegador. Use `?tema=claro` ou `?tema=escuro` no endereço para forçar o tema.

- `Painel.html`: telas (início, produtos, ficha do produto, categorias, marcas, consulta rápida, orçamentos, usuários e perfis, entrar).
- `dados.js`: 40 produtos de exemplo tirados do catálogo. **Códigos internos (EX-0001…) e impostos são fictícios**, porque o repositório é público (regra R2 da spec 002).
- `img/`: fotos e logos dos produtos de exemplo.

Como nos demais designs: replique os valores visuais (cores, tipografia, espaçamentos, comportamento); não copie o código do protótipo para produção.
